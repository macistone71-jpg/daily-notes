# Daily Notes

私人日常笔记与知识积累仓库。

## 目录结构

- `notes/YYYY/MM/YYYY-MM-DD.md`：每日笔记
- `templates/daily-note.md`：每日笔记模板

## 记录原则

1. 每天一篇，持续补充当天的新知识、想法和行动项。
2. 引用外部资料时保留链接，方便追溯。
3. 不写入密码、令牌、身份证件等敏感信息。
4. 未完成事项在下一篇笔记中继续跟进。
