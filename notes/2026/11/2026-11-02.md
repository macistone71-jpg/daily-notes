# 2026-11-02 AI 热点日报

> 今日可核实的重点集中在 Agent 实践与评测：记录 10 月 31 日发布、今天仍有高关注的 DeepSeek 原型，以及 11 月 2 日新发布的 GDPx。热度数字是检索时页面快照；基准结果属于发布方评测，不等同于独立复现。

## 今日热点速览

1. DeepSeek 发布仓库级 Super-agent 研究原型，主张把人工注意力保留给需要决策的环节。
2. SemiAnalysis 发布 GDPx Agent 基准：206 项任务覆盖 11 个专业领域，公开排行榜中最高分为 12%。

## 热点一：DeepSeek 的仓库级 Super-agent 原型（10 月 31 日发布）

### 发生了什么

DeepSeek Harness 团队在 GitHub 发布 `dsh-superagent-prototype`。官方仓库将其定义为面向单个 GitHub 仓库的主动式编程 Agent：在获准后监听 GitHub（可选接入飞书），创建工作项、在独立会话和目录中处理，并通过原始对话回复结果。仓库明确说明这是研究原型，不是官方产品，也未达到生产就绪状态；公开版本并不包含论文所述的所有设想。

### 为什么重要

它展示了从“一问一答”转向持续接收团队工作、按权限执行并把人类注意力留给决策和结果的 Agent 设计方向。对团队而言，关键不只是自动完成任务，还包括明确授权规则、隔离工作空间、控制通知频率和方便人工审查。原型的安全性、可靠性与维护成本仍需自行评估。

### 热度信号

检索时 GitHub 仓库页面显示约 9.8k stars、994 forks；GitHub 项目列表标注 MIT 许可。Hacker News 对应讨论页显示 11 分、约 1 天前发布。星标和 fork 反映开发者兴趣，不能证明代码成熟或功能有效；论坛分数也只是当时快照。

### 我的判断

值得关注的是它把“主动性”与“授权/注意力治理”放在同一设计里，而非单纯追求无人值守。官方文档同时强调它是研究代码、可能有缺陷，采用者应先检查权限、外部集成和执行隔离，不应直接接入关键仓库。

## 热点二：SemiAnalysis 发布 GDPx Agent 基准（11 月 2 日）

### 发生了什么

SemiAnalysis 发布 GDPx v1.0，覆盖芯片设计、网络安全、生物、金融、法律、量化交易、递归自我改进、硬件设计、材料、对齐和软件工程 11 个领域，共 206 项任务、14 家专业数据伙伴。官方排行榜列出 20 个参测模型中的 13 个；Claude Opus 5.5 总分 12.0%，Gemini 4 Carbon 为 10.9%，GPT-6 Astra 为 9.6%。发布方说明总分按每项任务三次尝试的 pass@1 汇总，并对领域等权。

### 为什么重要

GDPx 强调带工具、环境和专业流程的多步任务，与只在静态问答或文档生成上评测不同。若方法经独立检验，这类评测有助于判断 Agent 是否能在真实工作流里完成任务，而不只是在演示中表现流畅。

### 热度信号

基准发布于今天，官方页面公开排行榜、领域列表和合作方；同日已有多家 AI 行业资讯站转述结果，讨论焦点集中在“真实任务环境”与低通过率。此处尚未看到足够的独立复现，因此热度主要来自新基准发布及二次报道，不能视为评测共识。

### 我的判断

“最高 12%”只描述 GDPx 自定任务、评分和模型配置下的结果，不代表当前 AI 在现实工作中只有 12% 成功率。SemiAnalysis 自己指出安全分类器可能压低部分模型在网络安全、生物和对齐领域的得分；任务选择、合作方环境、评分细节和可复现性都值得继续审阅。它的价值首先是提出更贴近 Agent 工作流的测量议题，而不是给模型排出普适能力名次。

## 今日观察

Agent 进入团队工作流后，权限治理、人工介入点和执行环境，与模型能力本身同样关键。相应地，评测也需要从单轮回答扩展到真实工具环境中的多步任务；但新基准仍需公开方法、独立复现和跨领域验证，避免把单一排行榜当成行业定论。
