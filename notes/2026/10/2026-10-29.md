# 2026-10-29 AI 热点日报

> 检索时间：2026-10-29（Asia/Shanghai）。当天没有足够可靠、互动突出的全新模型发布；扩展到近 72 小时，重点记录 10 月 28 日 Gemini 4 Carbon 发布，以及企业 Agent 从模型调用转向受治理的工作流与运行时。

## 今日热点速览

1. Google 发布 Gemini 4 Carbon，第三方 Artificial Analysis Intelligence Index v5.0 将其列为当前首位；但首轮仅向部分网络安全防御团队开放，尚非普遍可用。
2. OpenAI 与 ServiceNow 扩大企业工作流合作，ServiceNow MCP 插件已上架；开发、安全和语音等更深集成仍有一部分处于计划或后续阶段。
3. Microsoft 将 Copilot harness 作为 Foundry Agent Service 公共预览，提供托管 Agent 循环、沙箱、技能、工具和子 Agent 编排，模型可选而非绑定单一模型。

## 热点一：Gemini 4 Carbon 登上独立综合榜首，但先限量开放

### 发生了什么

Google DeepMind 于 **10 月 28 日**公布 Gemini 4 Carbon，定位为长程工程任务与网络安全防御模型。Google 报告其在漏洞发现、利用验证和修补等任务上取得高分，并称其内部安全代码生成表现优于 Gemini 4 Argon；这些安全基准和内部评测数字仍属于厂商公布结果。

第三方 Artificial Analysis Intelligence Index v5.0 给 Carbon（High）评分 59，列为其测评模型中的第一名。该综合指数是独立评测信号，但不等同于所有真实工作流的胜出；该机构同时记录 Carbon 生成 token 量较高，成本/输出长度也应纳入比较。

Google 表示 Carbon 将先向 Fairwind 项目中的部分网络安全防御团队开放，并参与美国政府的发布前测试流程；开发者、企业和普通用户的开放时间尚未确定。因此“发布”不等于公众现在就能调用。

### 为什么重要

这是前沿模型能力与发布治理绑定的例子：当模型针对漏洞发现和利用等双用途任务增强时，厂商选择先限制访问、收集反馈并迭代防护。对安全团队而言，这可能带来更强的防御辅助；对行业而言，评估重点也从单纯榜单成绩扩展到访问资格、滥用防护和分阶段部署。

### 热度信号

Google 公告发布当天获得 Reuters、Ars Technica 等媒体跟进，Artificial Analysis 同日更新独立榜单。正式发布前，Gemini 社区已有关于 Carbon 的讨论，其中一条跟踪帖约 239 票；这是发布前关注度的快照，不代表正式发布后的普遍用户体验。

### 我的判断

“独立综合榜首”值得关注，但不应直接等同于最佳产品：Carbon 仍受限量访问，真实开发者体验尚少；Google 自报的网络安全优势也需要更多独立复测。后续应观察它在软件工程、漏洞修复和长时 Agent 任务中的成功率、成本、误报及边界控制，并确认更广泛开放的条件。

## 热点二：OpenAI 与 ServiceNow 将 Agent 接入企业工单与工作流

### 发生了什么

OpenAI 与 ServiceNow 于 **10 月 28 日**宣布扩大合作。新集成计划让用户在 ChatGPT 中查看 ServiceNow 业务上下文并执行获准的工作流动作；ServiceNow 的 Action Fabric 会应用组织已配置的业务规则与权限。ServiceNow MCP 插件已在 OpenAI marketplace 上架。

双方还计划把 Codex、OpenAI 模型与 ServiceNow 的应用开发、安全运营和语音产品结合。OpenAI 公告给出的时间表显示，部分功能仍要到 2026 年底或 2027 年进入预览/上线阶段，不应一概描述为已交付。

### 为什么重要

企业 Agent 正从“回答问题”走向读取工单、评估变更并更新业务记录。把工具执行放入现有权限和审批体系，有机会减少人工在多个系统间搬运信息；但错误动作、过宽授权和审计缺口也会随之放大。

### 热度信号

OpenAI 与 ServiceNow 分别发布了合作公告，ServiceNow 当日财报公告也提及合作扩展。未发现足以代表广泛用户热度的可靠互动数据；本条入选依据是双方公布的可执行产品范围及企业落地影响，而不是社交平台热度。

### 我的判断

短期可验证的部分是 MCP 插件和既有权限配置；其余功能需要按公告时间表继续观察。评估企业 Agent 时，应检查授权粒度、用户确认、操作日志、幂等性与撤销/回滚能力，而非只看演示里是否能完成跨系统操作。

## 热点三：Microsoft Foundry 推出可选的托管 Agent harness

### 发生了什么

Microsoft 于 **10 月 28 日**宣布 Microsoft Copilot harness 在 Foundry Agent Service 开放公共预览。托管层负责 Agent 循环和沙箱，开发者可以配置技能、MCP 等工具、身份验证与审批，并让 Agent 操作文件/代码或委派有边界的子任务。Microsoft 称可选用 20 多种前沿模型或自带模型；预览期 harness 运行时免费至 12 月 1 日，但模型推理及单独计费的工具仍收费。

### 为什么重要

Agent 产品的竞争正在从模型性能延伸到运行时：上下文管理、工具调度、文件执行、长任务恢复和安全策略会显著影响稳定性。托管 harness 可减少团队重复搭建基础设施，也可能增加对平台执行环境和定价规则的依赖。

### 热度信号

Microsoft 官方 Foundry 与公司博客同日宣布公共预览，并给出客户案例和具体计费日期；目前证据主要是厂商发布及案例陈述，尚无独立规模化采用数据。与 OpenAI–ServiceNow 的工作流整合公告并看，说明企业 Agent 基础设施与系统集成是近 72 小时的共同主题。

### 我的判断

托管运行时适合想快速验证多步骤 Agent 的团队，但需比较平台灵活性、模型可替换性、日志与沙箱边界、长任务恢复及总拥有成本。预览期间可验证 Agent 失败后的重复执行和副作用处理；免费运行时不代表模型调用或连接服务免费。

## 今日观察

- 近 72 小时的两条产品线共同指向“让 Agent 进入真实工作系统”：模型能力、企业权限、工具运行时和审计必须一起评估。
- Gemini 4 Carbon 的榜单成绩已由第三方测量，但公众可用性仍受限；Agent 平台公告则多数处于预览或分阶段交付。应把厂商承诺、第三方评测与实际采用分开记录。
